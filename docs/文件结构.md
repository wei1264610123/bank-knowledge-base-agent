## 启动顺序

### 1. 后端服务

```bash
cd backend

# 复制环境变量
cp .env.example .env

# 编辑.env文件，填写DASHSCOPE_API_KEY

# 安装依赖
pip install -r requirements.txt

# 启动服务
python run.py
```

### 2. 前端服务

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 3. 或者使用一键启动脚本

**Windows:**
```bash
双击 start.bat
```

**Linux/Mac:**
```bash
chmod +x start.sh
./start.sh
```
